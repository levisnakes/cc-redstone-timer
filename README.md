# CC Redstone Timer

ComputerCraft program that sends a redstone pulse out the back every 18 minutes. A redstone signal on top stops it, and the countdown restarts once that signal turns off.

## Install

```
wget https://raw.githubusercontent.com/levisnakes/cc-redstone-timer/main/redstone_timer.lua startup.lua
```

The settings at the top of the file control the interval, how long the pulse lasts, and which sides are used.
